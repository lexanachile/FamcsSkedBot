# Рыболовный клуб

Игра лениво загружается из fishing-loader.js. Доступны Дом и Переправа;
остальные точки закрыты. Каталог преподавателей находится только в Worker.

progress.js получает профиль через проверенный Telegram initData и хранит
неподтверждённые квитанции в IndexedDB, отдельно для каждого Telegram ID.
Обычные рыбки — валюта в кармане. Преподаватели — отдельная коллекция.
Старые демонстрационные трофеи из localStorage автоматически в D1 не
импортируются: у них нет серверного подтверждения. Старые данные не удаляются.

Автосохранение — раз в пять минут при новых уловах, плюс попытка при скрытии,
закрытии игры и восстановлении сети. В Доме есть кнопка Сохранить улов.
До ответа сервера квитанции остаются в IndexedDB. Закрытие WebView не
гарантирует отправку: при следующем открытии пакет можно дослать в течение
суток. Неудавшееся раскрытие улова восстанавливается до истечения токена
заброса (около десяти минут). Ошибки отображаются под сценой.

Дом показывает все слоты, непойманные закрыты. Есть у N рыбаков считает
сохранённые коллекции; статистика может отставать до пяти минут и более,
если другие игроки ещё не отправили свой пакет. При N=1/2 видны теги.

Вход на ПК — через Telegram Desktop/Web Mini App с initData. Самостоятельный
вход обычного браузера пока отсутствует. Без Telegram нельзя играть с
серверным профилем; расписание остаётся доступным.

Цвета: cloud-colors.js сохраняет полный JSON в miniapp_colors. Локальные
неподтверждённые правки накладываются на последнюю серверную версию, включая
удаления. PUT с устаревшей revision отклоняется. Подтверждение старой отправки
не очищает более свежие локальные правки. Синхронизация при открытии/фокусе,
раз в минуту в видимой вкладке и через три секунды после правки.
Состояние разделено по Telegram ID. Первоначальные локальные цвета и список
последних оттенков переносятся отдельно для каждого аккаунта. Миграция
считается завершённой только после подтверждённого PUT в API, поэтому после
ошибки сети или конфигурации она автоматически повторяется.

Управление skill-check: pointerdown, Space keydown. Сервер защищает
квитанции от подделки и повторов, но не проверяет каждое попадание.
Dev-время/погода влияют только на рисунок, сервер определяет награду отдельно.

Проверки: node --test pkgs/frontend/tests/*.test.mjs
После публикации вручную проверить Telegram на телефоне и ПК: вход,
пакетное сохранение, повтор после потери сети, изменения цветов на двух
устройствах, Дом, серые закрытые локации и полноэкранный режим.
