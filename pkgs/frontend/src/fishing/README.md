# Рыболовный клуб

Порядок публикации и настройки API/WebSocket:
[инструкция Cloudflare](../../../../docs/cloudflare-request-optimization.md).

Игра лениво загружается из fishing-loader.js. Обе SVG-сцены построены сразу в
портретной системе координат 450x600 (3:4), без обрезки горизонтального макета.
Доступны Дом и Переправа;
остальные точки закрыты. Каталог преподавателей находится только в Worker.

progress.js получает профиль через проверенный Telegram initData и хранит
неподтверждённые квитанции в IndexedDB, отдельно для каждого Telegram ID.
Обычные рыбки — валюта в кармане. Преподаватели — отдельная коллекция.
Старые демонстрационные трофеи из localStorage автоматически в D1 не
импортируются: у них нет серверного подтверждения. Старые данные не удаляются.

Улов сохраняется сразу при reveal. Пятиминутный таймер досылает только
старые неподтверждённые квитанции. В Доме есть кнопка Сохранить улов.
Игровые команды идут через одно WebSocket-соединение с HTTP-резервом.
Скрытие игры закрывает соединение после ответа на текущую команду.
До ответа сервера квитанции остаются в IndexedDB. Закрытие WebView не
гарантирует отправку: при следующем открытии пакет можно дослать в течение
суток. Неудавшееся раскрытие улова восстанавливается до истечения токена
заброса (около десяти минут). Ошибки и короткие статусы появляются поверх
игровой сцены.

Дом показывает все слоты, непойманные закрыты. Есть у N рыбаков считает
сохранённые коллекции; статистика может отставать до пяти минут.
Показываются до пяти случайно выбранных тегов владельцев каждой фразы.

Вход на ПК — через Telegram Desktop/Web Mini App с initData. Самостоятельный
вход обычного браузера пока отсутствует. Без Telegram нельзя играть с
серверным профилем; расписание остаётся доступным.

Цвета: cloud-colors.js сохраняет полный JSON в miniapp_colors. Локальные
неподтверждённые правки накладываются на последнюю серверную версию, включая
удаления. PUT с устаревшей revision отклоняется. Подтверждение старой отправки
не очищает более свежие локальные правки. Синхронизация при открытии/фокусе,
раз в десять минут в видимой вкладке вне рыбалки и через три секунды после правки.
Повторные focus/visibilitychange в течение минуты не перечитывают цвета.
При ошибках интервал повторов растёт до пяти минут.
Состояние разделено по Telegram ID. Первоначальные локальные цвета и список
последних оттенков переносятся отдельно для каждого аккаунта. Миграция
считается завершённой только после подтверждённого PUT в API, поэтому после
ошибки сети или конфигурации она автоматически повторяется.

Маленькая рыба ловится одним точным попаданием в сектор; более редкий улов
сохраняет многоэтапное вываживание. Pointerdown принимается в capture-фазе по
всей игровой сцене, а для iPhone/WebView есть touchstart fallback с подавлением
только парного события того же касания; Space срабатывает на keydown. Сервер защищает
квитанции от подделки и повторов, но не проверяет каждое попадание.
Dev-время/погода влияют только на рисунок, сервер определяет награду отдельно.

При поклёвке рыба появляется у поплавка и уходит влево, оставляя след на воде.
Енот целиком смещается вслед за натянутой леской. Во время skill check рыба
продолжает тянуть, а каждое нажатие запускает короткую подсечку удочкой по дуге.
Координаты тела, руки, рукояти, кончика удочки и точки заброса собраны в rig.js;
леска на каждом кадре строится строго между рассчитанным кончиком и пастью рыбы.

Магазин открывается с карты. Покупки сначала досылают ожидающий улов, затем
сервер атомарно списывает обычных рыбок. Экран снаряжения открывается в биоме
до заброса: удочка выбирается постоянно, активная прикормка расходуется по
одной порции. Dev-панель позволяет выбрать любую удочку и прикормку для теста;
На localhost серверные бонусы dev-режима доступны автоматически. В опубликованном Worker они доступны только TEST_TELEGRAM_USER_ID; для остальных игроков панель скрывается.

Проверки: node --test pkgs/frontend/tests/*.test.mjs
После публикации вручную проверить Telegram на телефоне и ПК: вход,
пакетное сохранение, повтор после потери сети, изменения цветов на двух
устройствах, Дом, серые закрытые локации и портретную игровую сцену.
