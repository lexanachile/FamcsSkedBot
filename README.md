Парсер эксель расписания фпми в удобную страницу famcs.online

Настройки Worker API (Cloudflare env; локально `pkgs/worker-api/.dev.vars`):

- `TEST_TELEGRAM_USER_ID`: Telegram ID модератора. Получает изменения всех групп всех курсов независимо от подписки. Пользователь должен предварительно запустить бота. Переменная нужна именно в API Worker, который формирует очередь уведомлений.
- `AVAILABLE_ROOMS`: JSON-массив постоянных аудиторий, например `["101", "102"]` (пример, не реальный список). Аудитории из расписания автоматически не добавляются. Без настройки `/api/rooms/free` возвращает 503.

`GET /api/rooms/free?dayOfWeek=1&pairNumber=1` возвращает свободные и занятые аудитории только из заданного списка. Учитывает пересекающиеся по времени занятия всех курсов и обе подгруппы. Это консервативная оценка недельного слота: условные занятия и даты в комментариях считаются занятостью.

`GET /api/teachers` возвращает уникальные фамилии без инициалов и дат. `GET /api/teacher?name=Пазюра` ищет точную нормализованную фамилию; однофамильцы объединяются, как и в существующем формате списка.
